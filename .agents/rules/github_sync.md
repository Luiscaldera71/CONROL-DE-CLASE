# Regla de Sincronización Automática con GitHub

Para este proyecto:
- Cada vez que se realicen cambios, correcciones o nuevas funcionalidades, se debe crear un commit descriptivo y hacer `git push origin main` al repositorio oficial:
  `https://github.com/Luiscaldera71/CONROL-DE-CLASE.git`
- Esto garantiza que el repositorio en GitHub y los despliegues automáticos en Vercel permanezcan siempre actualizados en tiempo real.
